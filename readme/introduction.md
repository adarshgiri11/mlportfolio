# Introduction

#### Machine Learning (ML)

Machine Learning (ML) is a branch of Artificial Intelligence (AI) that enables computers to **learn from data and make predictions or decisions without being explicitly programmed for every task**.

ML algorithms identify patterns in data and use those patterns to perform tasks such as image recognition, recommendation systems, spam detection, and predicting future outcomes.

**Main types of ML:**

* **Supervised Learning:** Learns from labeled data.
* **Unsupervised Learning:** Finds patterns in unlabeled data.
* **Reinforcement Learning:** Learns through rewards and penalties.

**Examples:** Google search recommendations, Netflix suggestions, face recognition, and self-driving technology.
